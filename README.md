从黑格尔到齐泽克：一本六章的书，一张九十一个格子的概念地图。

不需要哲学背景。每一章、每一格都不从定义开始，而从你大概经历过的场面开始。

- **书**：`book/` — 六章，从「我」怎么被安排讲起。在线读：`book/index.html`

在线阅读：`https://sinenter2026.github.io/critical-theory-primer/`（书 `/book/`，图 `/map/`）

**In English** — A primer on critical theory, from Hegel to Žižek: a six-chapter book (`book/`) and a clickable map of ninety-one concepts (`map/`). Written for readers with no philosophy background; every term enters through an ordinary scene rather than a definition. Written by an amateur reader; corrections welcome. 这两份材料是业余读出来的，入门水平：能核的出处都核了，核不到的地方标了等级；读错的欢迎直接指出。

## 一、它讲的是哪一路哲学

书里出现最多的是拉康（34 次）、马克思（28 次）、黑格尔（17 次），其次是阿尔都塞（9 次）、弗洛伊德（4 次）、巴迪欧（4 次）。

三条线索：

- **德国观念论**（黑格尔）：否定性、承认、实体即主体
- **政治经济学批判**（马克思）：账本、剩余、商品拜物教
- **精神分析**（弗洛伊德到拉康）：无意识、享乐、对象 a、主体空位

它们在一个问题上交汇：**为什么明知不对，还是照做。**

学术上这个名字叫意识形态批判，说得具体一点是拉康式马克思主义。这本书把它翻译成日常问题。

## 二、这两份东西想解决什么

读理论最难受的一步，不是看不懂词，是不知道这个词跟你今天有什么关系。

「大他者」听起来像神学，可它就是「上面要求的」里的那个「上面」：你顺着「这是谁定的」一路往上问，问不到具体的人，那就是它的位置。

「享乐」听起来像纵欲，可它是你明知道第二天要上班、还是把那一集看完的那股劲。

这两份材料做的事就一件：**把词放回你的一天里**。词跟着动作走，门槛就低了一截；反过来，先背定义，门槛会越垒越高。

## 二、书怎么用

六章，每章一套动作：三个场面 → 一组矛盾 → 一个被拆开的词 → 几个追问 → 一种别的读法 → 一次对社会的重看。

每节末尾有判据，就是那句「你能拿它来判什么」；每章末尾写了「可能错在哪」。

## 三、为什么给工具不给结论

读完一本讲社会的书，合上，记得几个词：内卷、异化、结构、算法。第二天照旧上班。过一个月朋友提起其中一个词，你想了两秒：「哦对，就是那个。」

问题不在你读得不认真。书给的是结论，结论最容易被忘掉。真正留下来的是看事情的角度，而角度不会自己长出来——它得在你遇到下一件事的时候被用上一次，才留得住。

所以书不给结论，给工具。六章，每章一套：三个你大概经历过的场面、一组矛盾、一个被拆开的词、几个追问、一种别的读法、一次对社会的重看。每节末尾有判据，每章末尾写了「可能错在哪」。

## 四、图怎么用

概念记不住，往往不是词太难，是不知道它跟你今天有什么关系。

比如「大他者」——听起来像神学。可它就是「上面要求的」里的那个「上面」：你顺着「这是谁定的」一路往上问，问不到具体的人，那就是它的位置。
