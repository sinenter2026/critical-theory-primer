# 出处台账

这里放的是这张图的账本。图上每句话后面标的「有出处／有出处（转引）／半有出处」，依据都在这几份文件里。

- `半有出处台账.md`：哪些格只到「转述」这一档，为什么升不上去。
- `引用分级核对.md`：书稿与图里每条引文的核对记录。
- `连线核查.md`：283 条关系逐轮体检的过程，改过哪些方向、哪些标签。
- `书网覆盖台账.md`：书里有的概念，图上有没有；反过来呢。

看这些不需要懂理论，只需要知道一件事：这张图不要求你相信它，它让你去查。

## 三档怎么定

原典级：能回原文、给行号；转引级：原典不在手边，标了转引来源；半有出处：只有转述或综合，不能当引文用。

## 怎么用

读到一个说法觉得可疑，先在图上找到那一格，看「依据怎么来的」和「原典位置」。

- 写「有出处」的，给的是原典行号，能回原文核；
- 写「有出处（转引）」的，原典不在手边，标了转引来源；
- 写「半有出处」的，只有转述，不能当引文用。

三档的区别不是谦虚，是能不能被反驳。
